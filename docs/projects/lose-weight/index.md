# 轻盈有数（lose-weight）

一款饮食记录 / 体重管理 Android App 的全栈项目，包含 **App、后端 API 与管理后台、官网** 三端。线上地址：<https://light.gaolin.xin>（[下载页](https://light.gaolin.xin/download)）。

| 端 | 技术栈 | 说明 |
| --- | --- | --- |
| Android App | Flutter | 五个主入口（首页/饮食/运动/体重/我的），arm64-only 包体约 11.6MB，Android 7.0+ |
| 后台与 API | Express + SQLite，管理后台 Vue | 单 Node 进程：用户/用量、模型与渠道、费用、资料库、App 发布、日志与任务 |
| 官网 | VitePress | 功能、下载、常见问题、隐私与更新说明，同源反代版本接口 |

## 🔗 线上入口

- 官网与下载：<https://light.gaolin.xin>
- 管理后台：`lightmanage.gaolin.xin`（内部使用）
- 版本接口：`/api/app/version`（官网下载页实时显示最新版本，失败时回退构建期写入的版本信息）

## 📱 App 核心功能

- **AI 记餐**：文字、拍照（最多 6 图）、语音转文字、外卖订单截图识别；多轮纠错与食量核对，逐项显示识别置信度，低置信自动追问或升级强模型
- **每日摄入方案**：登录后档案引导，AI 生成每日热量、三大营养素目标与三餐食物份量建议，失败可重试
- **自制菜品**：配料生重/做法、配料 AI 营养与熟重估算、食品秤逐行回填、熟重记餐与动态余量
- **商品库**：名称/品牌/条码查询、拍包装 AI 识别、多规格合并卡片、新增共享商品与纠错
- **运动识别**：任意运动 App 分享图多模态 AI 识别，核对日期与消耗后保存
- **体重与统计**：BLE 体重秤（小米 S200 加密广播）、趋势/均线/达标预测、外食频次、饮水
- **回顾与分享**：每日分析、AI 周报、每日海报与周报分享卡片
- **备份与更新**：JSON 版本 1–4 本机备份（含照片）、每日自动云备份（服务端保留 5 天）；应用内检查更新、SHA-256 校验与系统安装器覆盖安装
- **主题视觉**：四季色板按节气自动切换、节气当天换肤、天气胶囊与日签

## 🖥 后台能力

- 用户管理：启用/停用、重置密码、强制下线、AI 用量补足（新账号默认 20 点，失败退回）
- 模型与渠道：多渠道/多 Key、SSE 流式、重试与降级、预算（提醒/拒绝/切降级模型）、费用估算
- 资料库：食品 1677 条初始导入、菜品种子 50 道、共享商品维护
- App 发布：APK 上传/校验/发布/下架、最低版本控制、按天数清理（最新包始终保留）
- 安全：会话管理、注册开关与邀请码、每 IP/每用户限流、账号隔离备份

## 🛠 工程化

- Flutter 侧 700+ 项单元测试，发布前静态分析 + 签名 V2 + arm64 校验 + 公网下载哈希核对
- 发布流程：版本号按线上递增 → 构建 → 公网哈希核验 → 官网同步 → 版本接口确认，全程留档发布记录
- 三个子仓库经 `git subtree` 合并为单一仓库（Gitee `gaolin1234/lose-weight`），历史完整保留
- 密钥、签名、数据库与私人备份全部 Git 忽略，新构建不内置个人 token
